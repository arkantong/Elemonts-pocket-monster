# UI/UX Elemonts v0.1.18

[Unduh PDF lengkap](../../downloads/Elemonts-UIUX-Design-Complete-v0.1.18.pdf)

- Edisi 28 Oktober 2026, bahasa utama Indonesia.
- 101 halaman, 77 capture halaman/menu/state, 77 tautan indeks dan bookmark per halaman.
- Pembukaan, starter, tutorial menangkap, empat ruangan Home, makanan/tim/hadiah, Koleksi dan detail, skill/stat/duplikat, Jelajah dan battle, Trainer/Gym/Cup/Duel, Toko, Pengaturan dan pemulihan save.
- Panduan visual, navigasi, alur, komponen, daftar 37 bentuk monster, evolusi, 13 item, 24 skill, opsi menu, progres, audio, bahasa dan checklist handoff.

Ini dokumentasi implementasi 0.1.18, bukan rancangan fitur yang belum dibuat. Screenshot berasal dari browser dengan save QA, umumnya viewport 390×844 CSS px dan simulasi inset atas/bawah 24 px. Data progres pada gambar bukan akun pemain sungguhan. Native file picker/share/install UI tidak dipresentasikan sebagai halaman buatan game; variasi versi native Android dijelaskan dalam teks.

Home menggunakan ilustrasi 2D; battle masih 3D. Aset karakter/halaman lain masih berstatus prototipe. Batas fitur dan kebutuhan pengujian perangkat fisik dicatat pada bagian akhir PDF.

Validasi: 101 halaman terbaca, seluruh 77 tampilan memiliki bookmark dan gambar, tautan indeks berjumlah 77, tidak ada span teks terdeteksi di luar halaman. Cover, Home, detail, battle, indeks dan lampiran dirender ulang dan diperiksa visual. Tidak ada perubahan source game pada ekspor dokumentasi ini.
